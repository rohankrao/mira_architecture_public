Late Data, Upserts and Sources That Lie

Sources are not append-only streams: they publish late, edit in place, go down, and occasionally serve an error page as data
Mutability
⇄ A Document Has a Slot, Not an Append Log Upsert Model
  • • Upsert is the default. A positional doc_id means re-fetching the same slot updates it in place, instead of accumulating near-duplicate copies of one page.
  • • Changed content re-tags itself. The content hash is part of the cache key, so an edited document misses the cache while its unchanged neighbours keep theirs.
  • • Deletes are tombstones, never silent absences — “removed, and why” is what an audit asks for, and an absence cannot answer.
⚠ A Source That Lies Is Worse Than One That Is Down Isolation & Plausibility
  • • Down is easy: the source is skipped, its watermark left where it was, and it is reported. One unavailable portal does not fail a run spanning forty sources.
  • • Lying is the dangerous case. An empty file or an HTML error page saved as data gets curated cheerfully, so per-source volume deviation is checked before the content is trusted.
  • • Our own store failing mid-run costs the unfinished shards only — resume is shard-level, and verified by a kill -9 test rather than by argument.
  • • Readers never see a half-written dataset: atomic commit plus an alias, so a slow reader cannot block a writer and a writer cannot corrupt a reader.

🔍 Debugging a Record, Not a Log File Diagnosis
  • • “Why was this document dropped?” is a query — sel__decision, <op>__error, <op>__skipped and character spans are columns, so the answer is SQL rather than grep.
  • • Every operator-visible failure carries a stable code (MIRA_E0412), a one-line cause, a one-line remedy and a docs page bundled offline — because an air-gapped user has no search box.
  • • One root cause, one page. Identical failures collapse into one class with a count; a node or object-store alert inhibits the symptoms it causes instead of paging per partition.
  • • “Green” means checked. A stage committing zero rows where the plan estimated millions fails the run, and success is unreachable with a missing _SUCCESS.json.
  • • Resume re-executes no committed chunk; a driver crash costs at most one chunk per in-flight worker, and a changed operator recomputes only its own columns.
